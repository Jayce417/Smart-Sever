决策树连接功能测试

功能变更说明

  • 移除自动连接同名节点：不再支持输入节点名称自动连接所有同名节点
  • 改为手动选择连接：现在需要手动选择源节点和目标节点
  • 修复编辑连接保存问题：编辑连接时现在可以正确保存修改
  • 支持值和概率编辑：连接时可以设置分支值和概率

测试步骤

  1. 启动应用：npm run dev
  2. 添加几个节点（决策节点、概率节点、终止节点）
  3. 点击"连接节点"按钮
  4. 选择源节点和目标节点
  5. 设置连接标签、分支值、概率（如果适用）
  6. 保存连接
  7. 在连接列表中点击"编辑"按钮
  8. 修改连接属性并保存
  9. 验证修改是否正确保存

预期结果

✅ 连接对话框显示源节点和目标节点的下拉选择框
✅ 可以设置分支值和概率（概率节点）
✅ 连接列表显示连接信息和值/概率
✅ 编辑连接时可以修改所有属性并正确保存
✅ 不再支持自动连接同名节点

主要改进

  • 更精确的控制：用户可以选择具体的节点进行连接
  • 更好的用户体验：避免了同名节点造成的混淆
  • 完整的数据编辑：支持编辑连接的所有属性
  • 修复的保存逻辑：编辑连接时数据能正确保存
