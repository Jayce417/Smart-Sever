决策树可视化系统测试

系统概述

这是一个基于 Vue 3 的决策树可视化系统，支持三种节点类型：

  • 决策节点 (Decision Node)：用户可以选择不同分支的决策点
  • 机会节点 (Chance Node)：表示随机事件，包含概率信息
  • 结束节点 (Terminal Node)：决策树的叶子节点，包含收益值

分支格式说明

决策节点分支格式

("low", 300, "competitor_bid") # (标签, 值, 目标节点名称) ("medium", 500, "competitor_bid") ("high", 700, "competitor_bid") ("no-bid", 0, "profit")

机会节点分支格式

("low", 0.35, 400, "cost") # (标签, 概率, 值, 目标节点名称) ("medium", 0.50, 600, "cost") ("high", 0.15, 800, "cost")

功能测试步骤

  1. 启动应用：npm run dev
  2. 创建节点：
    • 点击"添加节点"按钮
    • 输入节点名称（如：bid, competitor_bid, cost, profit）
    • 选择节点类型
  3. 配置分支：
    • 双击节点进行编辑
    • 添加分支信息
    • 设置分支标签、值、概率（机会节点）
    • 输入目标节点名称
  4. 手动连接：
    • 点击"连接节点"按钮
    • 选择源节点和目标节点
    • 设置连接标签、分支值、概率
  5. 编辑连接：
    • 在连接列表中点击"编辑"按钮
    • 修改连接属性
    • 保存修改
  6. 导出/导入：
    • 测试导出功能
    • 测试导入功能

预期功能

✅ 支持三种节点类型：决策节点、机会节点、结束节点
✅ 决策节点支持最大化/最小化设置
✅ 机会节点支持概率和值的设置
✅ 结束节点支持收益值设置
✅ 支持分支格式：决策节点 (标签, 值, 目标节点)，机会节点 (标签, 概率, 值, 目标节点)
✅ 可视化功能：拖拽节点、双击编辑、实时连接线
✅ 数据管理：导出/导入 JSON 格式
✅ 连接管理：手动连接、编辑连接、删除连接

示例决策树

示例结构：
  • bid (决策节点) → competitor_bid
  • competitor_bid (机会节点) → cost
  • cost (机会节点) → profit
  • profit (结束节点)

分支配置示例

# bid 节点分支 ("low", 300, "competitor_bid") ("medium", 500, "competitor_bid") ("high", 700, "competitor_bid") ("no-bid", 0, "profit") # competitor_bid 节点分支 ("low", 0.35, 400, "cost") ("medium", 0.50, 600, "cost") ("high", 0.15, 800, "cost") # cost 节点分支 ("low", 0.25, 200, "profit") ("medium", 0.50, 400, "profit") ("high", 0.25, 600, "profit")

技术特点

  • Vue 3 Composition API：现代化的响应式开发
  • Element Plus：丰富的 UI 组件库
  • D3.js：强大的数据可视化能力
  • 拖拽交互：直观的节点位置调整
  • 实时编辑：双击节点快速编辑
  • 数据同步：节点和连接信息实时同步
